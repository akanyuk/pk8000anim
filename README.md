# pk8000anim

Парсер GIF-анимации для советского бытового ПК **ПК8000** («Сура», «Веста», «Хобби»).

- **`pk8000anim`** (Go, исходники в `main.go` + `internal/pk8000anim/`) — превращает
  GIF-анимацию в программу ПК8000, воспроизводящую её на экране (режим 2, 256×192).
  На выходе — исходники на ассемблере КР580ВМ80А (**плеер** `player.asm` и **данные**
  `data.asm` — отдельные файлы), скрипты сборки (Windows/Linux) и готовый `.cas`.
  Ассемблер встроен, внешних компиляторов не требуется — только Go.
- **`emu80-mcp/`** — эмулятор Emu80 с включённым MCP-сервером (автозагрузка `.cas`,
  скриншоты экрана PNG, чтение/запись памяти и портов по HTTP) — для автотестов.
- **`docs/PK8000_stroenie_ekrana.md`** — справочник по видеосистеме ПК8000.

## Установка

Скачать бинарник для своей системы со [страницы релизов](https://github.com/akanyuk/pk8000anim/releases)
(текущая версия — [v0.1.0-alpha.1](https://github.com/akanyuk/pk8000anim/releases/tag/v0.1.0-alpha.1)):

| Файл | Платформа |
|---|---|
| `pk8000anim-linux-amd64` | Linux x86-64 |
| `pk8000anim-windows-amd64.exe` | Windows x86-64 |
| `pk8000anim-darwin-arm64` | macOS (Apple Silicon) |
| `pk8000anim-darwin-amd64` | macOS (Intel) |

Переименовать в `pk8000anim` (`.exe` для Windows) и положить в каталог из `PATH`:

```sh
# Linux / macOS
install -m 755 pk8000anim-linux-amd64 /usr/local/bin/pk8000anim
pk8000anim    # выведет справку

# Windows (PowerShell)
Move-Item pk8000anim-windows-amd64.exe pk8000anim.exe
```

Либо собрать из исходников (нужен установленный Go):

```sh
git clone https://github.com/akanyuk/pk8000anim.git
cd pk8000anim
make            # все платформы в dist/; или: make build / go build -o pk8000anim .
```

## pk8000anim

```sh
go build -o pk8000anim .

# собрать анимацию из GIF
./pk8000anim parse testdata/anim.gif -o out -name anim
# -> out/player.asm, out/data.asm, out/build.sh, out/build.bat, out/anim.cas

# пересобрать исходники (то же делают build.sh / build.bat)
./pk8000anim asm out/player.asm out/data.asm -o out/anim.cas
```

`.cas` загружается в эмуляторе ПК8000 через Alt-F3 («Загрузить и выполнить»);
на реальной машине — командой `BLOAD"имя",R` с кассеты.

Флаги `parse`: `-o каталог`, `-name имя` (до 6 символов), `-border 0..15`
(цвет рамки), `-bw` (принудительно чёрно-белый режим; автоматически включается
для двухцветных GIF с чёрным и белым цветами). PNG не поддерживается.

Кадры выводятся **попиксельно (1:1)**: анимация меньше экрана — в левый верхний
угол, больше — невлезшая часть обрезается.

### Формат анимации (memsave)

Кадры хранятся как диффы к предыдущему кадру — формат memsave из проекта
[speccy_animation_parser](https://github.com/akanyuk/speccy_animation_parser),
адаптированный под видео-память ПК8000 (адреса физические, 0000h–37FFh):

| Код | Команда | Действие |
|---|---|---|
| `dw addr` | — | начальный адрес указателя экрана (кадр) |
| `%00nnnnnn` | COPY | вывести nnnnnn+1 (1..64) байт из потока |
| `%01nnnnnn` | SKIP | сдвинуть указатель на nnnnnn+1 (1..64) |
| `%100nnnnn` | **FILL** | заполнить nnnnnn+1 (1..32) байта следующим байтом |
| `%101yxxxx` | LONG SKIP | +xxxx×256 (+128 при y=1) |
| `%11xxxxxx` | END | конец кадра |

FILL — оптимизация формата: гряды одинаковых байт занимают 2 байта вместо 1+N,
а декодирование не медленнее COPY. Ключевой кадр хранится целиком и пишется в
видео-память при старте; массив цвета в чёрно-белом режиме константен.
Проигрыш зациклен бесшовно: последний дифф возвращает состояние к ключевому кадру.

Размер программы с данными ограничен памятью 4000h–EFFFh (~44 КБ): ключевой кадр
12 КБ + диффы + плеер.

## emu80-mcp

```sh
cd emu80-mcp
./run.sh            # запуск ПК8000 с MCP-сервером
```

MCP-сервер: `http://127.0.0.1:19781/mcp` (JSON-RPC over HTTP).
Основные инструменты: `emu_load`, `emu_run_for`, `emu_reset`, `screen`
(base64-PNG), `mem_read`/`mem_write`, `port_read`/`port_write`, `disasm`,
`cpu_state`, `kbd_text`. Строки в аргументах парсятся как шестнадцатеричные —
для десятичных значений передавайте JSON-числа.

Важно: конфигурация платформы передаётся **только** флагом `--conf-file`
(иначе эмулятор показывает модальный диалог выбора платформы до старта MCP).

Каталог `emu80-mcp/` самодостаточен: бинарник, конфиги, ПЗУ и шейдеры лежат
внутри репо, внешних файлов (включая установленный Emu80) не требуется —
достаточно склонировать репозиторий. Системные зависимости бинарника:
Linux x86-64 и Qt6 (`qt6-base`, `qt6-multimedia`; на Arch — `pacman -S qt6-base qt6-multimedia`).

Сборка эмулятора из исходников (если понадобится пересобрать):
`git clone https://github.com/vpyk/emu80v4 && cd emu80v4 && mkdir build && cd build
&& qmake6 MCP_SERVER=1 ../src/Emu80qt.pro && make`
(нужны Qt6 с модулями multimedia/widgets/openglwidgets).
