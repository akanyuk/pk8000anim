# Строение экрана компьютера ПК8000 (Хобби, Веста, Сура)

Источник — документация с сайта [pk8000.narod.ru](http://pk8000.narod.ru/):
книги «Сура ПК8000» (кн. 1–4), «Веста ПК8000» (кн. 1–3), «Хобби ПК8000» (кн. 1–3).

Основной материал — **Книга 2 «Язык Бейсик»**:
Приложение 6 «Структура видео-ОЗУ», Приложение 3 «Регистры ввода-вывода»,
Приложение 4 «Распределение памяти», раздел 3.4.12 «Управление экраном дисплея».

Все три модели — одна и та же машина (различия в разъёмах расширения и версии
встроенного Бейсика 1.1 / 1.2), видеосистема у них идентична. Отличается только
подача материала в книгах: у «Суры» — подробные карты с адресами, у «Весты» и
«Хобби» — компактная схема той же структуры.

---

## 1. Общая организация

Экран построен по «тайловой» (знакогенераторной) схеме, унаследованной от
MSX / видеоконтроллера TMS9918: изображение собирается из программируемого
знакогенератора (256 знаков 8×8 точек), буфера кодов и таблиц цвета.
Аппаратных спрайтов нет.

- **Видео-ОЗУ — 16 Кб**, собственное адресное окно `0000–3FFF`
  (в Бейсике — функции/операторы VPEEK и VPOKE, адрес 0…16383).
- Физически это 16 Кб из 64 Кб ОЗУ; какой банк ОЗУ отображается на экран,
  задают биты 15–14 регистра 84.
- Вывод изображения — на телевизор (вход ВИДЕО для чёрно-белого,
  адаптер на вход RGB для цветного).

## 2. Режимы экрана (оператор SCREEN)

| Параметр | Режим 0 | Режим 1 | Режим 2 |
|---|---|---|---|
| Оператор | `SCREEN 0` | `SCREEN 1` | `SCREEN 2` |
| Экран | 40×24, знакоместо 6×8 | 32×24, знакоместо 8×8 | графика 256×192 |
| Цвет | один цвет текста + фон на весь экран; рамка равна фону | цвет изображения/фона по **группе из 8 символов** (32 группы на 256 знаков) | цвет изображения/фона для каждого **отрезка из 8 точек по горизонтали** |
| Назначение | текст | цветной текст, игры, быстрая анимация сдвигом буфера | полноцветная графика, векторные иллюстрации, сложные игры |

Режим 2, по сути, повторяет экран ZX Spectrum, но цвет задаётся не для
квадрата 8×8, а для полоски 8×1 — цветовая детализация выше.

### Палитра (16 цветов)

Оператор `COLOR <цвет изображения>, <цвет фона>, <цвет рамки>`, значения 0…15:

| № | Цвет | № | Цвет |
|---|---|---|---|
| 0, 1 | чёрный | 8 | красный |
| 2 | зелёный | 9 | светло-красный |
| 3 | светло-зелёный | 10 | жёлтый |
| 4 | синий | 11 | светло-жёлтый |
| 5 | тёмно-синий | 12 | фиолетовый |
| 6 | бирюзовый | 13 | светло-фиолетовый |
| 7 | светло-голубой | 14 | серый |
| | | 15 | белый |

В режиме 0 рамка отсутствует (всегда равна цвету фона).
Системные ячейки: FA24 — цвет точки (переднего плана), FA25 — цвет фона,
FA26 — цвет рамки.

## 3. Раскладка видео-ОЗУ (Приложение 6)

### Режим 0

| Адрес | Область | Размер |
|---|---|---|
| 0000–05FF | буфер экрана: 24 строки по 64 символа; на экран выводятся первые 40 символов строки, в конце строки — служебные коды «05, 06, 07, 0D, 0E, 0F» для регенерации памяти | 1536 байт |
| 0600–07FF | не используется | |
| 0800–0FFF | знакогенератор: изображения 256 символов в формате 8×8 (на экране отображается 6×8) | 2048 байт |
| 1000–3FFF | резерв (могут лежать другие буферы и знакогенераторы) | 12 Кб |

### Режим 1

| Адрес | Область | Размер |
|---|---|---|
| 0000–02FF | буфер экрана: 24 строки по 32 символа (коды знаков) | 768 байт |
| 0400–041F | таблица цвета: по байту на группу из 8 кодов (00–07, 08–0F, …, F8–FF); в байте — цвет изображения и фона | 32 байта |
| 0800–0FFF | знакогенератор: 256 символов 8×8 | 2048 байт |
| прочее | не используется / резерв | 12 Кб |

### Режим 2

| Адрес | Область | Размер |
|---|---|---|
| 0000–07FF | знакогенератор верхней части экрана (массив изображения) | 2048 байт |
| 0800–0FFF | знакогенератор средней части экрана | 2048 байт |
| 1000–17FF | знакогенератор нижней части экрана | 2048 байт |
| 1800–1AFF | буфер экрана: три части по 256 байт (коды символов верха / середины / низа), 24 строки × 32 знака | 768 байт |
| 1B00–1FFF | не используется | |
| 2000–27FF | коды цвета знакогенератора верхней части экрана | 2048 байт |
| 2800–2FFF | коды цвета знакогенератора средней части экрана | 2048 байт |
| 3000–37FF | коды цвета знакогенератора нижней части экрана | 2048 байт |
| 3800–3FFF | не используется | |

Массив изображения (3×2048 байт) совпадает с растровыми данными 256×192 точек:
каждый байт — 8 точек по горизонтали. Массив цвета задаёт цвет изображения и
фона для соответствующих 8 точек. Коды в буфере экрана выбирают, какое из
256 изображений своей трети экрана выводить в данном знакоместе.

## 4. Подвижные базы областей

Адреса всех областей программируются — в видео-ОЗУ можно держать несколько
знакогенераторов, буферов и таблиц и переключать их.

Ячейки системной рабочей области:

| Ячейки | Назначение |
|---|---|
| FA05, FA06 | адрес буфер экрана (режимы 0 и 1) |
| FA07, FA08 | адрес таблицы цвета (режим 1) |
| FA09, FA0A | адрес знакогенератора (режимы 0, 1) либо буфер экрана (режим 2) |
| FA0F, FA10 | адрес массива изображения (режим 2) |
| FA11, FA12 | адрес массива цвета (режим 2) |

Аппаратные регистры (доступ через OUT / INP, Приложение 3):

| Регистр | Назначение | Поля |
|---|---|---|
| 90 | положение текстового буфера в режимах 0 и 1 | режим 1: биты 0–3 — разряды A10–A13 адреса (шаг 1 Кб); режим 0: биты 1–3 — разряды A11–A13, бит 0 = 0 (шаг 2 Кб) |
| 91 | положение знакогенератора (режимы 0, 1) или буфера экрана (режим 2) | биты 1–3 — разряды A11–A13 адреса (шаг 2 Кб) |
| 92 | положение массива графики (режим 2) | разряд A13 базового адреса (шаг 8 Кб) |
| 93 | положение массива цвета (режим 2) | разряд A13 базового адреса (шаг 8 Кб) |

| Регистр | Назначение | Поля |
|---|---|---|
| 84 | режим экрана и размещение видео-ОЗУ (чтение/запись) | биты 7–6 — разряды A15–A14 адреса видео-ОЗУ (выбор 16-кб банка ОЗУ); бит 5 — 0 = 32 знака, 1 = 40 знаков; бит 4 — 1 = графический режим; биты 3–0 не используются |
| 88 | цвета | режим 0: биты 3–0 — цвет переднего плана, биты 7–4 — цвет фона; режимы 1 и 2: биты 7–4 — цвет рамки, биты 3–0 не используются |

Соотношение режимов регистра 84: режим 0 — бит 5 = 1, бит 4 = 0;
режим 1 — бит 5 = 0, бит 4 = 0; режим 2 — бит 4 = 1.

## 5. Управление экраном в Бейсике (раздел 3.4.12)

- `SCREEN <режим>` — установка режима 0, 1 или 2.
- `WIDTH <длина строки>` — длина строки в режимах 0 и 1
  (после SCREEN — 40 или 32; допустимые диапазоны 1…48 и 1…52).
- `CLS` — очистка экрана в любом режиме.
- `COLOR <изображение>, <фон>, <рамка>` — цвета 0…15.
- `VPOKE <адрес видео-ОЗУ>, <данные>` / `VPEEK(<адрес>)` — прямой доступ
  к видеопамяти (адреса 0…16383).
- Графические операторы (LINE и др.) работают в режиме 2; по завершении
  программы (END, STOP, прерывание) машина возвращается в прежний режим.
- Режим 1: цвет группы из 8 символов задаётся VPOKE через таблицу цвета.

## 6. Примечания

- Процессор КР580ВМ80А; видеосистема близка к TMS9918 по организации
  видеопамяти и набору режимов, но без аппаратных спрайтов.
- У «Весты» и «Хобби» участок 1800–1FFF в режиме 2 подписан как «резерв
  2048 байта» — детальная раскладка буфера экрана приведена только в издании
  «Суры»; на деле структура у всех трёх моделей одинакова.
- Тот же порядок работы с экраном сохранялся у игрового автомата «Фотон»
  на базе ПК8000.
