Оператор DEF FN

DEF FN <имя-> (<параметр>)= <определение функции>

Этот оператор позволяет пользователю запрограммировать
свою собственную функцию. Здесь <имя-> означает допустимое
имя переменной соответствующего типа, оно становится именем
определенной функции, <параметр-> содержит имя переменной
в определении функции. Этой переменной будет присвоено зна-
чение при вызове функции, < определение функции>> есть выра-
жение, описывающее функцию.

Пример:

1@ DEFFN AB(I)=C*D/2+1 описание функции АВ;

26 В-=ЕМ AB(2) вызов функции AB;

39 DEF FN ВАО) =АБ-+ВЫ описание функции BNE стро-
кового типа.

Оператор DEF FN должен быть выдан до вызова функции,
иначе фиксируется ошибка <18> — «неопределенная функция
пользователя».
